Prefer another chat?

Asking a model from the server is a BoxLang+ feature (a license or a trial). Copy prompt and the chat links work without it.

The server is not set to call a model (ai.enabled and the bx-ai module). You can still copy the prompt with a redacted summary of this server and paste it into a chat of your choice.

The summary holds uptime, heap, request totals, recent error messages, slow statements and executor health. Passwords, parameter values and the configuration are never included.
