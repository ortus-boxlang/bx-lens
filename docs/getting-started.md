# Getting Started

## Install

=== "install-bx-module"
    ```bash
    install-bx-module bx-lens
    ```

=== "CommandBox"
    ```bash
    box install bx-lens
    ```

## Enable

Lens ships disabled. Turn it on in `boxlang.json`, under `modules.bxLens.settings`:

```json title="boxlang.json"
{
	"modules": {
		"bxLens": {
			"settings": {
				"enabled": true
			}
		}
	}
}
```

Restart the runtime. Every other setting has a default, so this is all you need. See [Configuration](configuration.md) for the rest.

## See the bar

Create a page and load it from the same machine.

```html title="index.bxm"
<bx:output>
	<h1>Hello Lens</h1>
</bx:output>
```

Open the page. A health strip appears at the bottom. Click it, or press ``Ctrl+` ``, to open the panel.

<!-- screenshot: overview.png generated by e2e -->
![The collapsed health strip and the opened panel](assets/screenshots/overview.png)

Add a message and a timer from code:

```javascript
lensMessage( "Page loaded", "info" );
users = lensMeasure( "load users", () => {
	return queryExecute( "SELECT 1 AS id" );
} );
```

See the [BIF reference](guides/bifs.md) for all functions.

## Runtime notes

::: columns
::: column
### MiniServer
Works out of the box. Lens serves its assets from `/~bxlens/` on the same host and port.
:::
::: column
### CommandBox
Works with the BoxLang engine. Install the module the usual way and enable it in the server's `boxlang.json`.
:::
::: column
### Servlet containers
Lens targets the same request flow as MiniServer. The spec lists confirming this on servlet and CommandBox as an open item, so test your setup and report problems.
:::
:::

## Requirements and limits

- Lens only injects into HTML responses (`text/html` by default). Other responses are collected but show no bar. See [History](panels/history.md).
- Callers must pass the [access rules](security.md). By default only loopback and private network addresses see the bar.
- Pages need a closing `</body>` tag for exact placement. Without one, Lens appends the bar at the end of the response.
